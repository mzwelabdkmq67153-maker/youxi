### 3.4 骁龙 680 档位判断（不把桌面 FPS 当手机帧率）

**硬件口径**：骁龙 680 = Kryo 265（4×A73 2.4 GHz + 4×A53 1.9 GHz）+ Adreno 610（约 1.11 GHz，128 ALU，≈0.284 TFLOPS，3DMark Wild Life 约 440 分级），LPDDR4X；属入门级 GPU，重负载手游需降画质且帧不稳。

**按本局实测负载折算（720p / 像素比 1、中低特效前提）**：

| 档位 | 三角/帧 | draw calls | 蒙皮实例 | 680 判断 |
|---|---:|---:|---:|---|
| 1 主角 + 3 敌人（敌人 1024） | ≈70.1 k | ≈85 | 3 × 21 骨骼 | **预计贴近 30 fps，不保证稳 30**：三角量对 610 不重（30 fps × 70 k ≈ 2.1 M 三角/s），主要风险在 CPU 侧——85 次 draw call 派发、3 个 AnimationMixer 每帧更新与 WebGL/JS 开销，A73 偏弱；爆发特效/光斑帧可能掉到 20–28 fps。 |
| 1 主角 + 6 敌人（敌人 1024） | ≈115.2 k | ≈104 | 6 × 21 骨骼 | **预计多数帧低于 30 fps（约 20–28 区间）**：瓶颈是 CPU draw call 派发 + 蒙皮/mixer 更新，不是三角面或贴图带宽。 |
| 全 2K 敌人贴图 | 同上 | 同上 | 同上 | **不建议上 680**：191.52 MiB 解码驻留 + 贴图带宽压力，入门级显存/带宽余量不足。 |

**瓶颈排序**：① draw call 派发 / CPU 蒙皮与 mixer 更新（主瓶颈）；② 像素填充（夜景半透明光斑、特效叠加）；③ 贴图带宽（次）；④ 三角面（最轻）。

**后续优化方向（不在本轮实现）**：敌人合批或合并材质以压 draw call；锁定敌人 1024；远处敌人降骨骼/暂停 mixer 更新；移动端像素比上限 1；爆发特效减半透明叠加层数。

## 4. 已知缺陷与修复记录（模型/加载器侧，游戏侧不遮罩、不掩盖）

1. **已修：FIT 归一，boss 超模解除**。此前内层 `fit` 按目标身高 3.330/1.96 烘焙（1.699），又被 `game.js` 根节点 `scaleOf(boss)=1.85` 二次放大，网格实测 6.162 m。最终版 FIT 归一为 `1.800 / GLB 名义身高`（grunt 0.978 / shooter 0.952 / duelist 0.952 / elite 0.978 / boss 0.918），类型放大全部交给根 scale；复测纯网格：grunt 1.794 m、shooter 1.836 m、boss 3.331 m，达标。
2. 模型侧已知缺陷（seam 已记，不遮罩）：枪手步枪左下碎屑；术士下摆内衬暗块；术士法杖分段；剑客腰侧鞘偏移。若资产修复后有变化，以加载器组最终版本为准。
3. **术士（mage_idle）手臂动作叠加已禁用**：资产下摆/袖顶点权重未绑到 Hips，可见抬臂会拖拽飞片/斜条；该模型肩/上臂/前臂叠加一律 off，只保留胸/颈微动（Chest ≤0.10、Spine ≤0.05、Head ≤0.08）。
   - 局内 **boss 不触发骨骼动作叠加**：`bossBurst()` 只放弹幕，`game.js` 不调 `Hero3D.swing`，boss 模型在 PVE/PVP 里不会出现攻击动作帧。
   - 远端术士施法同样受此限制（手臂叠加 off），施法可读性由胸/颈微仰 + 法杖持手姿态承担；待 Blender 重绑袖/摆权重后，再按 0.55–0.75 放开手臂叠加。
4. 验收页 HUD 身高读数含夜间剪影面罩/脚下冷光 sprite，比纯网格包围盒高 0.2–0.5 m；身高判定以纯网格 `Box3` 为准（§3 表内数字均为纯网格口径）。

## 5. 回退方式

**URL 开关（`index.html` 统一入口）**：

| 参数 | 档位 | 说明 |
|---|---|---|
| 无参 / `?art=glb` | GLB 写实档（默认） | `window.Hero3D = Glb3D`；优先。 |
| `?art=real` | 旧程序化写实档 | `Real3D`。 |
| `?art=ink` | 水墨低模 | `hero3d.js` 原样，不覆盖，必须一直能跑。 |

**运行时回退链**：GLB 档下 `Glb3D` 不可用（脚本/loader 缺失）→ 回退 `Real3D` → 再回退 `hero3d`，不允许白屏；单实例 GLB 加载失败 → 该实例回退 `Real3D`（`glbFallback` 标记）。

**贴图档位**：默认策略 `Glb3D.setTierPolicy({ hero: '2k', enemy: '1024' })`（接口由加载器组提供；接入侧防御性调用，接口缺失则跳过）。强制档：`?tex=1024` 全员 1024。

**验收页调试钩子**：`window.__glbDbg`（`ready / hit / kill / planted / debug / stats / info / bytes`），仅存在于 `_ingame_glb.html`，未污染 `index.html`。
