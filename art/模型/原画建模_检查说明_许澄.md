## 一、前提

三张原画是 AI 生成概念图（图上带生成水印），按本项目红线只作**形制参照**：几何按身体实测半径重建，贴图自己画，不做 AI 直出。原画只给了正/侧/背三个视角、没有背面结构与材质细节的地方，我按对称和已有材质槽补的。

## 二、本轮做了什么

1. **材质**：新增自发光槽 `M.glow`（`MeshBasicMaterial` + `toneMapped:false`），剑刃线、护目镜、枪口环、袍纹、法杖球共用；三职业 `accent` 按原画改成青/青/紫。
2. **装束分职业**：`gear()` 分发到 `gearSwordsman / gearGunner / gearWarlock`，`gearGeneric` 留给杂兵、精英、BOSS。
   - 剑客：整圈胸甲壳、胸口中脊、青色刃光横条、压扁肩甲两层 + 外角尖、深蓝布腰封、前/后腰甲弧片 + 两侧小块、背后两条飘带、前臂护臂、胫甲。
   - 枪手：科技甲底板、上胸/下腹两片弧壳、立领、青色斜挎带、星芒胸章、压扁肩甲、腰包三只 + 大腿包、前臂装甲带青光、护膝弧甲。
   - 术士：垂到脚踝的长袍、金属披肩、腰带布结 + 前垂布、半截护臂、袍摆紫色发光裂纹。
3. **武器按原画重做**：直刃长剑（刃口一条青线，不再并排第二把刀）、粗管步枪（枪口青光环）、荆棘杖（三根刺 + 紫球 + 光环）。
4. **发型按职业**：剑客高马尾（发髻 + 四根实体发束）、枪手短刺发 + 青色护目镜、术士尖兜帽（罩壳 + 后倾尖角 + 帽口压边）。
5. **靴与裤**：靴改成靴筒 + 脚掌 + 靴头 + 两层靴底，落地不穿地；剑客裤腿加宽 12%、枪手 4%；胫甲/护膝按加宽后的腿半径重算。
6. **修掉一个底层错误**：`loft()` 的三角形绕序是反的，单面壳体从正面看会被背面剔除——上一轮"肩甲、胫甲像浮在体外的灰板"就是这个原因（我们看到的是壳的背面）。改绕序后所有壳体外表面朝外，光照也一起正常了。
7. **局内接入**：`index.html` 默认回到水墨档，写实档改成 `?art=real` 显式打开，符合"检查通过再进游戏"。

## 四、已验证

- 三视图形制：肩甲、胸甲、腰甲、腰封、护臂、胫甲、靴、武器、发饰的主要识别点都对得上原画。
- A-pose、举臂：三职业均通过（肩甲挂胸廓，举臂不跟着飞）。
- 深蹲、弓步：**剑客与枪手不通过**（膝前裤料自穿、髋侧与腰甲互穿）；**术士不通过**（长袍没有布骨，蹲下腿从袍里穿出来）。

## 五、明确不达标（我这边判退稿的部分）

1. 头部仍是原型级：脸偏长、下颌偏重、耳是贴片；短发壳还是"蘑菇盖"，发际线是几何切出来的直线，原画是向后梳的短发。
2. 金属没有层次：胸甲是一整片壳，缺原画的叠层甲片和倒角，全靠贴图噪点撑；近景会显得"塑料"。
3. 手没有握持关系：武器挂在手腕节点上，五指是直的，握剑/握枪不是真握把。
4. 布料没有褶皱和垂坠：长袍是一根光滑圆锥，蹲下没有形变。
5. 枪手斜挎带是十八片小板拼的，远景读得出来，近景是锯齿。
6. 帧率没测：目标机型档位仍未定（暂按骁龙 680），19k tris、100+ 网格，三个同屏要合批。

## 六、需要拍板

1. 三张原画是**同一角色的三套职业外观**，还是三个不同角色？现在是按同一套身体 + 三套装束做的。
2. 术士长袍是否加 3–4 根布骨（约 +8 骨、+1.5k 面）做垂坠与摆幅？不加就只能接受术士不做蹲/跑特写。
3. 剑客/枪手的腰甲、腰包按原画做了实物层，穿模风险跟着上升；这个层数保留还是压回一层？
4. 检查通过后，局内是否直接把 `?art=real` 改成默认？
