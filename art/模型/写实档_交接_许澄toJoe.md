## 4. 材质槽位与贴图

| 槽 | 用在哪 | 材质 |
| --- | --- | --- |
| `skin` | 前臂、手、颈、耳 | 程序化肤色 + 噪点，roughness 0.63 |
| `face` | 头（球面 UV） | 2048 面部贴图：眼、眉、唇、鼻孔、颧部血色 |
| `hair` | 发壳 | 发丝纵向条纹，roughness 0.62，DoubleSide |
| `cloth` | 衣服、裤 | 织纹，roughness 0.90 |
| `leather` | 肩甲、腰带、护腕、靴、剑柄 | 皮革颗粒 |
| `metal` | 剑身、扣件、靴底 | 拉丝，roughness 0.42 |

**面部这一条要特别说**：眼窝、鼻梁、下颌的转折是**几何做**的（符合定型标准里的"眼窝与鼻梁转折必须实做"），眼睛的形、上下眼睑、眉毛、唇色是**2048 贴图画**的。理由很直接——这个面数级别靠几何雕五官，只会在 20 米外看还行、近看一团；贴图脸加几何转折才是手游写实的通行解。要改成全几何五官，得先把头部面数翻到 60k 以上，那是另一档预算。

## 5. 部件拆分（给 Joe 量产）

每个 kind 共用同一套骨架与拓扑，量产件只换部件，不重做骨架：

1. `head_surface`（头壳 + 面部贴图 + 3 组 morph：一笑 / 一怒 / 一痛）
2. `hair`（发壳，独立网格，便于换发型）
3. `neck` + 颈圈
4. `torso`（胸廓 / 腰 / 骨盆三段放样，重叠处已压进衣服，不露缝）
5. `arm_upper`（衣袖）+ `pauldron`（挂胸廓）+ `elbow_guard` + `forearm_skin` + `wristband`
6. `hand`（五指三节 + 拇指两节，LOD0 分段，LOD1 并块）
7. `leg_upper` / `leg_lower`（裤）
8. `boot`（靴筒 + 脚掌 + 靴头硬皮 + 靴底两层）
9. `belt` + `tasset`（短摆，只到胯下 9 cm）
10. `weapon`（剑 / 枪 / 杖，挂 `wristR`，独立 group）

量产注意：`pauldron` 与 `tasset` 都是**独立件**，挂胸廓与骨盆，不挂四肢骨——这是为了极限姿势下不跟着甩出去。复制到其他角色时必须保持这个挂法。

## 6. 绑定测试记录（`?mode=pose`，v1 实测）

| 姿势 | 结果 | 说明 |
| --- | --- | --- |
| A-pose 基准 | 通过 | 腋下布线合理，无夹面 |
| 举臂（肩部极限） | 通过 | 肩甲留在肩上，袖口与肩甲之间有 4 mm 缝，可接受 |
| 深蹲（膝髋极限） | **不通过** | 膝前出现两处裤料穿插（浅色面），髋侧与短摆边缘互穿 |
| 弓步（髋部扭转） | **不通过** | 髋侧裤面互穿，短摆前缘切入大腿 |

**结论：v1 不能作为定型件交付。** 按红线"绑定测试不通过不交付，也不以上线前再修作为理由"，这两条要修完再走定型评审。修的方向已经定了：膝部加一圈过渡环线并把膝骨点前移 8 mm；短摆前缘改成两片分离、各挂一根辅助骨，蹲下时随髋抬起。不需要重做拓扑。

## 7. 接入方式（这部分是给 Joe 的改动）

`art.js` 的 `buildHeroHD / buildFighterHD` 只认 `window.Hero3D`，运行时取值，所以在 `index.html` 里加两行就生效，`art.js` 与 `game.js` 一行不动：

```html
<script src="hero3d.js"></script>
<script src="real3d.js"></script>
<script>
  (function () {
    var q = new URLSearchParams(location.search);
    if (q.get('art') === 'ink') return;          // 回退开关
    if (window.Real3D) window.Hero3D = window.Real3D;
  })();
</script>
```

回退：地址栏加 `?art=ink` 即回老的水墨低模，不用改代码、不用回滚分支。

验证方式：打开 `_real_seam.html`，HUD 三行都要是 `(Real3D)` 且 `userData.hero3d = true`；再打开 `index.html` 进一局，看主角与敌兵的实际体型与材质。
