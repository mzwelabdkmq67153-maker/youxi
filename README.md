# 第七竞技场 · SEVENTH ARENA

第一人称 3D 竞技场原型。一个本地网页就能跑，包含 **PVE 副本** 与 **PVP 对决** 两种模式，支持剑客 / 枪手 / 术士三个职业。

## 运行

方式一：直接双击 `index.html`（Chrome / Edge 均可，`file://` 下也能跑，因为不加载任何外部资源）。

方式二：用项目自带的本地服务器（推荐，行为最接近线上）

```powershell
cd 游戏
node serve.js          # 默认 http://localhost:8080
node serve.js 8123     # 或指定端口
```

`serve.js` 只监听 `127.0.0.1`，同网段其他设备访问不到；对 `..` 目录穿越、畸形百分号编码返回 400。如果要让同事试玩，改用 `python -m http.server` 并自行控制防火墙。

依赖只有本地 `vendor/three.min.js`（Three.js r128），不联网也能玩。

## 模式

**PVE 副本**：波次刷怪，逐波增强，每 5 波出现 Boss。死亡即结算，记录抵达波次与击杀数。

**PVP 对决**：与 AI 对手（Duelist）1v1，先到 3 杀获胜。AI 会保持距离、侧向绕行、射击，并非站桩靶子。

## 职业

| 职业 | 主攻击 | Q | E | R |
|---|---|---|---|---|
| 剑客 | 扇形近战斩击 | 突进斩 | 旋风斩 | 剑域（6 秒持续伤害） |
| 枪手 | 射线射击，16% 暴击倍伤 | 战术翻滚 | 爆裂弹 | 火力全开（8 秒双倍射速） |
| 术士 | 法球投射，范围爆炸 | 冰霜环（减速） | 相位闪现 | 陨星（大范围重击） |

## 本地自检记录（2026-11-19）

服务端（`node serve.js 8123`）：

| 用例 | 结果 |
|---|---|
| `GET /`、`/index.html`、`/game.js`、`/vendor/three.min.js` | 200 |
| `GET /../../Windows/win.ini`（`--path-as-is`） | 400 拒绝 |
| `GET /%2e%2e%2f%2e%2e%2fWindows/win.ini` | 400 拒绝 |
| `GET /%zz`（畸形百分号编码） | 400 拒绝，进程不崩 |
| 监听地址 | `127.0.0.1`，非 `0.0.0.0` |

客户端：菜单 / PVE / PVP / 三职业 / 结算 / 重生 / 暂停 实测可进入，无控制台报错。

本轮修掉的问题：

1. `serve.js` 用 `startsWith(ROOT)` 做前缀判断，同级同名目录（如 `游戏2\`）可被读取 → 改为 `path.relative` 段级校验。
2. `serve.js` 的 `decodeURIComponent` 未捕获异常，一个畸形 URL 就能让服务进程退出 → 加 try/catch。
3. `serve.js` 监听全网卡 → 改为仅 `127.0.0.1`，并补 `nosniff`、`HEAD`、`Content-Length`。
4. 柱子遮挡用包围球判定，射线在 y≈1.2 处打过去也不会被 4.4 米高的柱子挡住 → 改为圆柱求交。
5. 投射物命中只比水平距离，朝天打的法球能命中地面敌人 → 加高度带 `0.1~2.4`。
6. 近战敌人隔柱打人 → 加水平视线检查 `losBlocked`。
7. 每局重建武器时旧武器只从相机摘除、不释放几何与材质 → 补 `disposeGroup`。
8. 菜单里按住的 WASD 会带进新一局 → `startGame` 清空按键状态。
9. 切到后台时游戏继续跑，人是离开的却掉血死亡 → `visibilitychange` 自动暂停。

## 已知限制

- 敌人贴到面前时模型会占满镜头（碰撞半径偏小，仍在可玩范围）。
- 近战扇形实际张角 132°（`arcDeg` 按半角解释），比字面看起来更宽。
- 伤害数字弹出未做合并，高射速下同屏数量偏多。
