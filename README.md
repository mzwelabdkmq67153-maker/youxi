# 第七竞技场 · SEVENTH ARENA

第一人称 3D 竞技场原型。一个本地网页就能跑，包含 **PVE 副本** 与 **PVP 对决** 两种模式，支持剑客 / 枪手 / 术士三个职业。

## 运行

方式一：直接双击 `index.html`（Chrome / Edge 均可）。

方式二：起一个本地服务器（推荐，避免个别浏览器的 file:// 限制）

```powershell
cd 游戏
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

依赖只有本地 `vendor/three.min.js`（Three.js r128），不联网也能玩。

## 操作

| 操作 | 按键 |
|---|---|
| 移动 | W A S D / 方向键 |
| 视角 | 鼠标（进入后自动锁定指针） |
| 攻击 | 鼠标左键（按住连发） |
| 冲刺 | 空格（带冷却） |
| 技能 | Q / E / R |
| 暂停 | Esc（同时释放鼠标） |

## 模式

**PVE 副本**：波次刷怪，逐波增强，每 5 波出现 Boss。死亡即结算，记录抵达波次与击杀数。

**PVP 对决**：与 AI 对手（Duelist）1v1，先到 3 杀获胜。AI 会保持距离、侧向绕行、射击，并非站桩靶子。

## 职业

| 职业 | 主攻击 | Q | E | R |
|---|---|---|---|---|
| 剑客 | 扇形近战斩击 | 突进斩 | 旋风斩 | 剑域（6 秒持续伤害） |
| 枪手 | 射线射击，15% 暴击 | 战术翻滚 | 爆裂弹 | 火力全开（8 秒双倍射速） |
| 术士 | 法球投射，范围爆炸 | 冰霜环（减速） | 相位闪现 | 陨星（大范围重击） |

## 已实现

- 第一人称视角、指针锁定、鼠标转向、镜头摇晃
- 竞技场：地面网格、四面墙、8 根立柱，玩家与敌人碰撞
- 三种敌人（近战 / 远程 / 精英）+ Boss（扇形弹幕、召唤援军）
- 伤害判定：近战扇形、射线命中 + 柱子遮挡
- 伤害飘字、命中标记、粒子、爆炸、屏幕震动
- 技能冷却、能量消耗、HUD、结算面板
- WebAudio 合成音效，无外部音频资源
