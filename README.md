# 第七世界 · SEVENTH WORLD

第一人称 3D 动作原型，按《第七世界 · 游戏策划案 v1.0》落地的一套可玩底层：**六职业 / 六段世界 / 四档副本 / 75 级 / 五档稀有度 + 银武 / +1–+10 强化 / PVE 与 PVP 分轨**。一个本地网页就能跑，包含 PVE 副本、PVP 对决与局域网对战三种模式。

规则层单独抽在 `core.js`（`window.Rules`），数值只在那里改一处，战斗、掉落、菜单、存档全部跟着走。

## 运行

方式一：直接双击 `index.html`（Chrome / Edge 均可，`file://` 下也能跑，因为不加载任何外部资源）。

方式二：用项目自带的本地服务器（推荐，行为最接近线上）

```powershell
cd 游戏
node serve.js          # 默认 http://localhost:8080
node serve.js 8123     # 或指定端口
```

`serve.js` 只监听 `127.0.0.1`，同网段其他设备访问不到；对 `..` 目录穿越、畸形百分号编码返回 400。如果要让同事试玩，改用 `python -m http.server` 并自行控制防火墙。

依赖只有本地 `vendor/three.min.js`（Three.js r128），不联网也能玩。

## 入口流程：开始页 → 世界 → 角色 → 世界内部

页面打开只有标题与一个「进入游戏」，其余全部后置，按三段走完才进场：

1. **开始页**：标题 + 等级 / 角色绑定状态 / 职业开放进度三个角标，没有别的选项。
2. **世界**：六段世界卡（等级或徽记不够的灰化，只提示不切），选完按「进入 XXX」。这一步只决定场景、难度与掉落。
3. **角色**：可选职业（P0 六 + P1 已开放四），页面顶部有一块**3D 预览**——模型缓慢自转、地台环取职业色，切职业即时换模型（走 `window.Hero3D`，所以 `?art=real` / `?art=ink` 也各用各的资产；机位按包围盒自动取景，长袍/重甲都不会裁头）。按「确认角色 · 进入世界」后**写入存档并锁定**；此后任何入口都不再出现角色页，想换只能清档重开。
4. **世界内部（hub）**：面板浮在当前世界场景右侧，**副本四档 / PVP 对决 / 局域网对战都在这里选**，技能加点与洗点也在这里（角色锁定不等于技能锁死），按主按钮（「进入普通副本」「进入 PVP 对决」「连接并进入房间」）真正开局。Esc 暂停、结算页、联机退出都回到这一层，不再退回整屏菜单。

| 阶段 | 能改什么 |
|---|---|
| 开始页 | 无 |
| 世界 | 世界（受等级 / 徽记门槛限制） |
| 角色 | 职业（仅首次，确认即锁定） |
| 世界内部 | 玩法（副本 / PVP / 局域网）、副本档位、换世界、技能加点与洗点；**职业不可换** |

角色与锁标记存在 localStorage（`cls` + `clsLocked`）：刷新后开始页直接显示「XXX · 已绑定」，进入世界时跳过角色页。

## 模式

**PVE 副本**：波次刷怪，逐波增强，每 5 波出现 Boss。死亡即结算，记录抵达波次与击杀数。

**PVP 对决**：与 AI 对手（Duelist）1v1，先到 3 杀获胜。AI 会保持距离、侧向绕行、射击，并非站桩靶子。

**局域网对战**（真人对真人）：同一 WiFi 下两台电脑，各自填同一个房间号即可 1v1。需要先起联机服务端，见下面「局域网联机」。

## 局域网联机

```bash
# 房主的电脑上起服务端（同端口既是网页也是 WebSocket）
node server.js 8123 --lan     # 局域网模式，会打印本机 IP
# 双方浏览器打开 http://<房主IP>:8123
```

- 只在本机自己试：`node server.js 8123`（只监听 127.0.0.1），两个浏览器窗口都开 `http://localhost:8123`。
- 房主在世界内部点「局域网对战」→ 填昵称 →「连接并进入房间」，页面给出 4 位房间号；对手填同一个房间号进来，双方自动开打。
- 房间上限 2 人，满员/已结束会收到明确提示；对手掉线会回到等待面板。
- 局域网连不上先看 Windows 防火墙有没有放行 node.exe 的入站连接。

**网络架构（有意取舍）**：位置与朝向由客户端按 20Hz 上报，服务端只仲裁血量、比分、胜负与复活。这样不用把整局战斗搬进服务端，代价是不防改包——定位是局域网朋友对打，不是公开匹配。

| 消息 | 方向 | 作用 |
|---|---|---|
| `hello` → `welcome` | C→S / S→C | 客户端就绪后握手，服务端下发 id、职业血量、出生点、房间比分 |
| `opponentJoined` / `opponentLeft` | S→C | 对手进出房间 |
| `state` | C→S→C | 位置/朝向/动作（idle/run/jump/attack），客户端做插值 |
| `hit` | C→S→C | 上报伤害，服务端 clamp 后扣血并回执 |
| `kill` / `respawn` / `matchEnd` | S→C | 击杀播报、复活、结算 |

## 等级与世界（GDD 第 4 章）

- 升级需求 `need(L) = 5L² + 180L`，上限 **Lv 75**，累计 **1 230 250** 经验。
- 六段世界按等级开，神之领域另需 **3 枚徽记**：

| 世界 | 区间 | 场景 |
|---|---|---|
| 新手村 | 1–10 | village |
| 主城 | 10–30 | city |
| 边境野外 | 30–50 | wild（枯树 / 岩堆 / 篝火残址 / 木栅栏） |
| 断崖战场 | 50–65 | cliff（断桥 / 弩台 / 裂痕 / 破旗） |
| 王座回廊 | 65–75 | throne（王座 / 金柱 / 垂幔 / 烛台） |
| 神之领域 | 徽记 3/3 | peak |

- 属性推导：等级主属性 `14 + 3.1L`；装备主属性 `8 + 2.6 × ilvl`（ilvl 上限 80）；基础攻击 `60 + 主属性 × 1.4 + 武器主属性`。
- 经验收支：普通怪 `L×10`、精英 `L×50`、BOSS `L×120`、清波 `60 + 波次×20`、主线 `L×400`、日常 `L×120`、竞技场胜 `L×120` / 负 `L×40`、事件 `L×200`。

## 装备（GDD 第 7 章）

- **五档稀有度 + 银武**：白（0 词条）/ 绿（1）/ 蓝（2）/ 紫（2 + 技能等级 +1）/ 橙（3 + 唯一被动）/ 银武（2 + 1 自选词条）。
- **12 槽**：P0 开放前 6 槽（武器 / 胸甲 / 护腿 / 战靴 / 项链 / 戒指），后 6 槽（头盔 / 肩甲 / 护手 / 腰带 / 副手 / 第二戒指）已建结构、暂锁。
- **主属性分流**：武器 100% 进攻击，饰品 50% 进攻击，防具按 1.2 倍折成生命。
- **强化 +1–+10**：+1–+5 必成，+6–+10 成功率 75/65/55/45/35%，失败掉 1 级，每级主属性 +3%，费用 `ilvl × 35`。背包里按 `=` 强化当前选中件。

## PVE / PVP 分轨

PVE 全额；PVP 伤害 ×0.55、控制时长 ×0.6、硬直 ×0.75、治疗 ×0.8、装备词条按 70% 生效（`Rules.playerStats(..., 'pvp')` 用参考等级 75 折算，避免高等级装备碾压）。

## 场景（按「美观设计」五张图与两张平面搭建）

`scene.js` 只做视觉与障碍，**玩法占地仍然是 ±22 的方场**，所以场景按“圆场 + 外圈看台”放大到能装下刷怪范围。

| 场景 | 落地件 | 实测 |
|---|---|---|
| 竞技场（PVP） | Ø45 圆台、三圈看台（每圈抬 1.2m）、朱红柱列 84 根、四根断柱（45°、半径 10.2m、高 9m 带断口）、六处 1.1m 掩体、双层符阵穹顶（加法面片，不进几何）、远山剪影 | 22 mesh / 6037 面 / 10 个障碍 |
| 首领厅（PVE） | Ø45 圆厅、中央 Ø6 祭石台（断成四块、缝隙发青蓝光）、五根断柱、八处矮掩体、四向兽面浮雕、朱红帐幔、熔岩缝、石闸门（下沿 1.9m）、藻井三环 | 21 mesh / 3800 面 / 17 个障碍 |

- 看台斗拱与窗格不建模，只留轮廓；穹顶符纹走两张 1024 环形贴图 + 加法混合。
- 光按场景分气质：竞技场暖白日场（雾色 `0x8ea3b4`），首领厅冷青地宫（雾色 `0x0a1418`）。
- 进场切换：`startGame()` 里 `syncScene()`——PVE 进首领厅，PVP 留竞技场；换场先清空障碍再由场景重登记。

## 打击感（GDD-COMBAT-HITFEEL-001）

`hitfeel.js` 单独一层，只负责"判定命中之后怎么演"，不改任何判定与伤害数值。

| 档位 | 触发 | 顿帧 | 震屏 | 推镜 | 闪白 |
|---|---|---|---|---|---|
| light | 普通命中 | 0 | 0.03 / 0.05s | 无 | 无 |
| heavy | 重击、第 3 段连段 | 1–2 帧 | 0.08 / 0.10s | 0.08 | 无 |
| crit | 暴击、击杀 | 3 帧 | 0.15 / 0.14s | 0.08 | 0.55 |

- **空挥不演**：`HitFeel.whiff` 只出风声，不出撞击音、震屏、冲击波、闪白。
- **同目标节流**：同一目标 3 帧内只播一套完整特效，避免连射刷屏。
- **顿帧不冻 UI**：顿帧只压 `anim` 里的模拟步长（`dilation()` 返回 0.15/0.05），HUD、音频、网络上报照常走真实时间。
- **调试面板**：F3 或任意 URL 加 `?hf` 展开，显示帧号、分节、档位、判定窗、顿帧、震屏与最近 6 条命中记录；八项开关可逐条关掉验证"关掉特效不动判定"。

命中到表现在已核对：判定帧内出特效，镜头位移与震屏叠加后不超过单次幅度上限。

**实测结论（桌面参考，2026-11-23，本地 8091 端口）**：

- 加载体积：敌人 1024 三份 GLB 合计 5.87 MiB（6,159,028 B）；全 2K 三份合计 11.18 MiB（11,724,308 B）。冷启动首挂本机约 0.28–0.62 s/份；缓存命中后同模型克隆实例化约 0.37–0.68 s/份。
- 渲染（场景遍历口径）：1 主角 + 3 敌人 ≈ 85 draw calls / 70.1 k 三角；1 主角 + 6 敌人 ≈ 104 draw calls / 115.2 k 三角。单模型 14.0–16.0 k 三角、21 骨骼、6 材质。

- 每 10.5 s：`groundSlam` 以自身为圆心 4.4 m、0.9 s 预警的裂地，圈内必须离开。

**咒缚主祭的技能循环**：
- 每 3.0 s：在玩家落点埋**双圈**咒缚（`castHexTrap`，1.25 s 延迟、2.9 m 半径、伤害 `自身伤害 + 12`）。
- 每 8 s：召 3 只蚀虫（虫群封走位）。
- 每 9 s：`bossBurst` 紫色弹幕。

**预警圈是"敌方专属"**。`spawnDelayedBlast` 的第 7 参 `hostile` 决定归属：敌方圈只在玩家处于 `半径 + 0.5` 时打玩家，**不会**误伤自己召唤的小怪、也不会自残；玩家技能的圈仍然只打敌人。这是早期版本的一个设计错误（BOSS 裂地会炸掉自己的召唤物），已修正。

**波次编队**（`buildWaveQueue(wave)`）：

- 数量 `wave 1 取 3，之后 min(30, 3 + wave * 2)`。
- 解锁与权重：蚀虫（第 2 波起，66%）、射手（第 3 波起）、石傀（第 4 波起，50%）、咒术师（第 4 波起，34%）、守关（第 6 波起，18%），保底填充杂兵。
- 每 5 波出 BOSS：第 5 波守卫长、第 10 波咒缚主祭，之后按 `cycle % 2` 交替；**第 20 波起双 BOSS 同场**（按 cycle 奇偶决定出场顺序）。
- 播报按 `TYPES[t].name` 去重拼接：`BOSS 来袭 · 守卫长` / `双 BOSS 来袭 · 咒缚主祭 + 守卫长`。

**辨识标记**（`decorateEnemy`）：四套美术档的模型贴图互不相同，配色差异在 GLB 档里被贴图吃掉，因此 BOSS 与小精英额外挂程序化发光环（加色混合、随时间自转）：守卫长头顶金环 + 脚下金环，咒缚主祭背后两道紫竖环，石傀脚下灰蓝环，咒术师头顶小紫环。这样在写实档 / 低模档 / 水墨档里都能一眼分出层级。

**调试参数**：
- `?wave=N`：从第 N 波起手（clamp 1–60），用来直接跳关底波看编队。
- `?boss=warden|oracle|boss`：清空波次队列，只在正前方 12 m 摆这一只 BOSS，用来单看它的走位、弹幕与召唤（不带 `sandbox` 才能看到咒缚圈真掉血）。
- `?bestiary=1`：把石傀 / 蚀虫 / 咒术师 / 守卫长 / 咒缚主祭并排摆成一行并冻结 AI，用来比对体型与光环。

**实测结论（2026-11-24）**：`?boss=oracle` 单挑场，血量 130 → 98 → 66，确认咒缚圈按延迟起爆并结算到玩家；剩余敌人从 1 涨到 4，确认蚀虫召唤；弹幕球可见。`?boss=warden` 近距离可辨体型约 1.6 倍于杂兵、青色大剑 + 头顶金环。`?bestiary=1` 五只并排层级清楚，蚀虫有意保持极小的体量。

**边界**：小怪与 BOSS 的数值是首版手感值，未做逐波难度曲线校准；召唤物没有数量上限（长局靠玩家的清怪速度压制）；BOSS 不做怒气/狂暴二阶段，双 BOSS 同场只靠出场顺序区分。

## 玩家等级 · 经验曲线（GDD 4.2）

PVE 里获得经验、累积等级，**等级跨局保留**，写在 `localStorage` 的 `seventh_the7.progress.v2`（兼容读旧的 `seventh_arena.progress.v1`）。PVP 与局域网对局不结算经验，也不吃等级与装备加成。

升级需求 `need(L) = 5L² + 180L`，上限 **Lv 75**：

| 目标等级 | 本级所需 | 累计 |
|---|---|---|
| 2 | 190 | 190 |
| 10 | 2 300 | 11 825 |
| 30 | 9 900 | 130 975 |
| 50 | 21 500 | 444 125 |
| 75 | 41 625 | 1 230 250 |

经验来源（`Rules.XP`）：普通怪 `L×10`、精英 `L×50`、BOSS `L×120`（按**内容等级**算，低等级内容按 `xpDecay` 衰减）、清波 `60 + 波次×20`、主线 `L×400`、日常 `L×120`、竞技场胜 `L×120` / 负 `L×40`、事件 `L×200`。

## 属性推导（GDD 4.4 / 7.2）

```
等级主属性  attr(L)      = 14 + 3.1 × L
装备主属性  itemMain(i)  = 8 + 2.6 × ilvl      （ilvl ≤ 80）
基础攻击    atk          = 60 + attr × 1.4 + 武器主属性
生命        hp           = 职业基准 + 防具主属性折算（1.2 倍）
秒伤        dps          = atk × 职业普攻倍率 / 攻击间隔
```

75 级裸装基准：attr 246.5、atk 608、秒伤 832；满 6 槽紫装（ilvl 75）：atk 893、秒伤 1 222。全部由 `Rules.playerStats(cls, lv, gearTotals, mode)` 一处推导，战斗里不再出现硬编码伤害。

## 技能点与洗点（GDD 5.3）

- 每级 1 点，30 级一次性补 10 点成就 → **75 级合计 85 点**。
- 单个技能上限 5 级：每级伤害 +8%，第 3 / 5 级各 −1 秒 CD，第 4 级范围 +20%。
- 洗点费用 `等级 × 200`，退回全部已花点数。

## 死亡惩罚

- 副本里死一次 **掉一级**，本级经验清零（结算面板多一行 `Lv 4 → Lv 3`）。
- 1 级有保护，避免新档被清空卡死；PVP 与联机不扣等级。
- 只扣等级不扣装备（装备本来就只在当局有效）。

### 后三段世界的专属地貌（`addWorldProps`）

共用几何之外，边境野外 / 断崖战场 / 王座回廊各挂一层**只属于这个世界的道具**，用基础几何拼（每件 3–6 个面，单世界 24–56 个 mesh），全部注册进碰撞障碍，可以贴着走、可以绕：

| 世界 | 专属件 | 落点 |
|---|---|---|
| 边境野外 | 枯树 6 株、岩堆 4 处、篝火残址 2 处、半塌木栅栏 3 段 | 台面外环 r 15.5–22 |
| 断崖战场 | 断桥 2 段、弩台 2 座、裂痕 5 道、破旗 3 面 | 台面外环 r 19–22 |
| 王座回廊 | 三层台阶王座 + 金柱 4 根 + 垂幔 2 面 + 烛台 6 座 | 王座在 -z 中轴，金柱 r 9.6 |

两个配套约束：道具层在 `build()` 里就建好（不等异步 GLB，避免前几秒空场），材质会打 `noEnv` 标记不吃环境贴图（否则深色木石会被洗成大理石白），只有王座金件保留 1.25 倍反照。
